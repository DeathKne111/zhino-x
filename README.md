## 核心特性

### 1. 精简大总结架构 & 稳定撤回/保留闭环
- **移除每楼小总结，融合大总结**：彻底清除每楼一次的小总结链路；`Sn()` 单次请求统筹「客观时间轴 + 地点库 + 物品库」，`Wn()` 并发生成角色第一人称记忆；自动 / 手动 / 批量三入口统一合并图谱与建向量。
- **纯「地点 + 物品」精简图谱**：移除冗余的角色位置、道路关系、关系网、NPC 小传与关系档案注入开关，专注高准确率的地点与物品归属追踪。
- **角色记忆「当时情感温度」保真**：强化 `Wn()` 第一人称记忆书写规范（事与情一体、忠于当下心境不事后洗白，保留约定与挂念 / 心结与伏笔 / 秘密与信息差），让角色长对话后既不失忆、也不丢当时的情绪余温。
- **大总结撤回与恢复彻底修复**：
  - 修复撤回大总结后游标 `lastSummaryAtMessageId` 读到旧缓存卡死、导致始终显示「0 条可总结」的致命 Bug，并内置**旧脏存档自动自愈校准**；
  - 点「撤回」自动取消隐藏本轮覆盖楼层（不误放上一轮已隐藏楼层）；点「恢复」自动重新隐藏并刷新 UI；允许撤回失败的 V1 总结。
- **选定楼层总结 & 批量总结自动保留近期楼层**：自动尊重设置中的「不总结楼层数（`preserveRecentFloors`）」，直接选到最新楼层时自动扣除最后 N 条受保护 AI 回复，补总结早期旧楼层时则绝不误砍。

### 2. 全量角色记忆远期向量召回 & 15 倍 Int8 压缩瘦身
- **普通非核心旧记忆纳入远期向量召回**：打破原版仅给核心记忆建向量的限制，核心与普通旧记忆统一纳入远期混合召回（语义 + Overlap 词汇覆盖率 + 时间衰减 + 核心温和加权 `+0.08`），话题提及远期日常细节时也能精准唤醒；无向量降级时自动开启安全闸防爆 Token。
- **Reranker 近期记忆隔离保护**：修复 `rerankEnhancedRecall` 未透传 `queryEmbedding`、破坏全量注入/单角色上限及重排误裁近期记忆的问题，确保近期轮次 100% 完整保留。
- **全三类向量 Int8 + Base64 紧凑编码（体积直降 ~15 倍）**：
  - 角色记忆、时间线事件、知识图谱节点全部采用单份 `q8:<scale>:<b64>` 压缩存储（1024 维从 `~21.5 KB` 降至 `~1.38 KB`，余弦最大误差 `< 0.0005`），彻底消除核心记忆双份重复序列化；
  - 内置无损迁移安全网：保存聊天或点击「统计 / 为旧数据生成向量」时自动将老存档旧明文向量本地无损压扁（**0 API 消耗**），彻底避免长聊记录文件膨胀。
- **编辑防脏向量**：修改记忆正文时自动清除过期向量，仅改时间或切换核心标记时保留原向量。

### 3. 解梦模块（Ny-Sigon 深度剖析 + 三块独立编辑）
- **原生多段深度剖析**：解除单行 JSON 与「每维一句话」限制，支持原生 `[Matrix]` / `[偏好风格]` / `[剧情建议]` 多段展开；`[偏好风格]` 按 `[WritingStyle]` 范式从六维反推剧情质感，绝不干涉预设文笔。
- **8 段消息链精确对齐**：`user_input` 精确落在 `<分析文本>` 标签内；喂入最近 15 轮清洗后对话 + 大总结时间线 `<summary>` + 上次六维 `<previous_matrix>` + Roll 次数信号。
- **三块独立可编辑 & 撤回持久化**：基于标准 Vue 3 `defineComponent + h()` 响应式子组件实现，六维解析 / 剧情建议 / 偏好风格均可独立编辑保存并同步预设槽位；撤回支持清空最后一条并持久化，空状态可一键恢复。

### 4. 全分块自然人话槽位注入 & MVU 零残留清理
- **原地定位桩替换**：`<!--ZHINO_...-->` 槽位原地精准填充，无数据或开关未开时自动清理并输出清晰诊断日志（明确标注「设置中『xxx』未开启」）。
- **自然人话引导词**：全分块重写为贴合创作视角的自然引导词（无「预设 / 系统 / 后台 / NPC」等出戏词，兼容抢话与不抢话，自动代入真实用户名）。
- **MVU 额外解析轮精确清理**：升级标签清理正则支持带属性与同前缀嵌套标签精确配对，确保 MVU 解析轮整块清零无残留。

### 5. 反代兼容、Nudge 还原与召回设置持久化
- **OpenAI 协议后端代理自动回退**：直连优先，遇 CORS 或网络拦截自动切换酒馆同源后端代理（附 `type: 'quiet'`，自动兼容 `400` 非标参数重试，支持 API 测试与手填模型名）。
- **Nudge 真实用户输入全链路还原**：优先读取楼层 `extra.qqz_nudge.text`（兜底 `<nudge>`），开聊自动回补历史 `userInputRecords` 并打印计数进度。
- **角色召回设置跨总结持久化**：单角色的「语义召回 / 全量注入」开关与「注入条数」跨多轮大总结与未出场轮次永久保留。

## 快速导入与升级

### 方式一：一键导入薄壳 JSON（推荐）

1. 下载或复制薄壳文件链接：
   ```text
   https://cdn.jsdelivr.net/gh/DeathKne111/zhino-x@v1.0.2/zhino-x-v1.0.2.json
   ```
2. 打开 SillyTavern / TauriTavern → **扩展** → **酒馆助手（Tavern Helper）** → **脚本库** → **导入**，选择 `zhino-x-v1.0.2.json` 并启用。
3. 刷新页面即可生效（控制台/日志出现 `智脑X v1.0.2 已加载`）。

### 方式二：手动新建 / 修改脚本链接（CDN）

在酒馆助手脚本库中新建或编辑已有「智脑」脚本，将内容替换为：

```js
import 'https://cdn.jsdelivr.net/gh/DeathKne111/zhino-x@v1.0.2/dist/index.js'
```

### 方式三：本地文件加载

将本仓库 `dist/index.js` 放入酒馆 `extensions/third-party/zhino-script/dist/index.js`，脚本内容填写：

```js
import '/scripts/extensions/third-party/zhino-script/dist/index.js'
```

## 必看配置说明

1. **解梦注入需开启两道门**：
   - ① 在预设中启用对应槽位条目（含 `<!--ZHINO_DREAM_PLOT-->` / `<!--ZHINO_DREAM_PREF-->`）；
   - ② 在智脑X「设置」中勾选 **「解梦注入」** 总开关（默认关闭）。
2. **老聊天补齐向量 & 自动瘦身**：
   - 升级后，打开已有聊天进入智脑X「设置 → 召回设置」，点击 **「统计」** 即可自动将历史旧明文向量无损压缩 15 倍（不花 API）；
   - 如需为历史普通旧记忆补齐向量以支持远期召回，点一次 **「为旧数据生成向量」** 即可，无需重跑大总结。
3. **TauriTavern 自定义反代授权**：
   - 首次通过后端代理访问新反代域名时，TauriTavern 会弹出原生端点授权确认框，请手动点击允许。
